# Exploratory research extension v2 — 2026-11-21

This extension was specified after v1 final results were inspected. It is exploratory, not preregistered confirmatory evidence. Preserve v1 protocol, receipt and final artefacts unchanged. Do not rerun the final period or tune any model/policy using this extension. The existing operational weekday baseline is unchanged.

Question: how stable are forecast-method differences over more historical weeks, and do forecast rankings agree with inventory outcomes under common constraints?

Use the same canonical, first-60-day selected five-product subset. Last complete date L=max transaction date minus one day. Evaluate thirteen non-overlapping seven-day folds at origins L-98, L-91, ..., L-14, ending at L-7. No target or training row can enter the original final target window L-6 through L. Methods and hyperparameters remain v1's five fixed methods. Training ends at each origin; report every selected product, every fold and any failures. Unequal method coverage invalidates paired inference; never silently compare different samples.

Primary descriptive forecast metrics: global WAPE with actual-unit denominator, MAE, signed bias and per-fold totals. Compare each alternative to weekday mean using synchronized week blocks containing all products, retaining cross-product dependence and within-week temporal dependence. Circular moving-block bootstrap uses two consecutive weeks per sampled block, thirteen weeks per replicate, 2,000 replicates, seed 20261121; recompute the ratio numerator and denominator in every replicate. Report percentile 95% resampling intervals for paired WAPE differences in percentage points, valid/undefined replicates and the block assumptions. Thirteen weekly blocks are few; nonstationarity, residual longer dependence, selected products and unadjusted multiple comparisons limit interpretation. These are exploratory resampling intervals, not causal effects or guaranteed population confidence statements. Include block-length sensitivity 1, 2 and 3 weeks without selecting the most favorable interval.

Decision robustness: all fifteen forecast/policy combinations over five scenario seeds 2026–2030, using the v1 default fourteen-day observed-sales replay and assumed costs, capacity and weekly cash grants. Seeds vary shared lead-time jitter; observed sales do not change across seeds. Every combination within a seed must have the same exogenous hash and proxy denominator. Report mean/min/max scenario cost and fill rate, and paired cost wins/ties/losses versus weekday-mean greedy. Five seeds cover limited supplier-jitter sensitivity, not independent historical demand experiments. Retain daily logs, terminal inventory and cost components. Keep the earlier eight one-factor sensitivity regimes unchanged as separate evidence.

Provide parameterized read-only reports and SQL window examples. Observed sale value is approximate descriptive revenue, not procurement cost, margin or profit; ABC segmentation uses first-60-day units and is descriptive within the selected subset only.
